

### memory banks
I think it would make the most sense if one memory card holds multiple memory banks. because I want to use a PCIe connector the card would be too small in comparison if I would only put one bank on each card. I am thinking of maybe 4 per card. each card then has jumper or dip switches or simple two close vias that can be brigded to set which card is which *or* the mem cards don't really have any logic and the slot where you put it in decides which one is which. The second option would provide a better user experience.
